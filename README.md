# Bangla Handwritten Upazila–District Recognition

A live AI-powered web application for recognizing handwritten Bangla Upazila–District names from images.

## What it includes

- Handwritten image upload
- Manual image cropping
- Upazila & District recognition
- Prediction confidence score
- Top predictions
- Interactive web interface

## Technologies Used

- Python
- Streamlit
- PyTorch
- Vision Transformer (ViT-Base)
- ConvNeXt-Tiny
- Weighted Soft Voting Ensemble
- OpenCV
- NumPy
- Pillow
- Hugging Face
- Transformers
- timm
